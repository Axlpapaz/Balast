Commmands
/balast : runs the lines written in config menu
/balastconfig : opens the config menu

CONFIG
Delay (sec) : you can type a number from 0,1 to infinity and that will be the interval count in seconds between each line

Channel : choose which chat will the lines be broadcasted

Enter the lines bellow. Each line seperates with "enter" 

Save to keep the changes

Use it by typing /balast or add the command /balast inside any macro you use

E.G.
1. open /balasconfig 
2. type in delay box 0,2 choose /raid 
3. type "X" lines for example 2 here
4. Blessing of Protection used on %t
   Blessing of Protection used on %t
5. Create a macro
#showtoolip
/cast [@mouseover,help,nodead][help,nodead][@player] Blessing of Protection
/balast

That will say in /raid Blessing of Protection used on <your target's name> twice with 200ms delay between the messages
You can use any mouseover or different macro you want.

There is a bult in spam protection. If you want to spam again you need to stop using the /balast command for 1,5 seconds
